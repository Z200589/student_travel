# 成员与账单编辑

## 操作入口

- 同行 AA 页面：成员名字下面点击“改名”，输入新称呼。成员 ID 保持不变，历史付款、分摊与结算仍属于同一人。
- 同行 AA 页面：消费明细点击“编辑消费”，自动滚动到上方表单并填入原记录。可改金额、说明、日期、分类、付款人及参与平摊成员。查看分摊预览后保存修改，或取消编辑。
- 预算页面：点击消费记录，选择“编辑”。普通消费复用原表单；AA 消费进入同行 AA 页面，再点击对应记录的编辑按钮。

## 记账行为

编辑更新原账单，不新增重复记录，保留 ID 及原有其他字段。金额、分类等改变后，预算总额、图表和 AA 余额读取同一份更新后的记录。

已经记录的线下转账保留。例如两人共同消费 10 元，甲付款，乙已还 5 元；把消费改为 20 元后，乙还需支付 5 元。把消费改小或改变付款人也可能产生反向应收应付，按新建议核对实际转账即可。编辑不发起实际扣款或退款。

成员称呼不允许空白、超过 20 字符或与别人重名。账单编辑限制为正数人民币金额、最多两位小数、有效日期及分类；AA 分摊整数分验证，普通消费不能通过编辑直接变成 AA 消费。存储失败保留原记录；打开编辑后账单若已变化，则拒绝旧表单保存，须重新打开。

## 验证与后续

1449 原断言与 68 回归测试通过（本次新增 8 项）。28 WXML、28 WXSS 编译通过，页面脚本语法和 diff 检查通过。包括真实服务已结算账单重算、付款人/参与人修改、一分钱、成员改名、过期编辑拒绝、失败不写入及两类页面保存测试。

手机上输入法、弹窗和自动滚动仍需实际验收。当前仍为本机账本，没有跨手机多人同步；成员删除与不等额分摊暂未提供。后续优先微信登录、协作权限与同步后台。
