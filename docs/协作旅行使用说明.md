# 协作旅行使用说明

入口：我的 → 协作旅行。当前为独立的协作副本：本地行程不会自动覆盖，后台修改也暂不写回本机。

## 本机体验

本轮已启动后台：http://127.0.0.1:8087，仅监听本机。若关闭或重启后服务不在，双击工程 backend/start-local.cmd 启动（占用 8087 的服务已经运行时不要重复启动）。

1. 微信开发者工具重新编译项目，打开“我的→协作旅行”。
2. 保留后台地址 http://127.0.0.1:8087，点击“连接后台”。本地开发若提示请求域名校验问题，在工具“详情→本地设置”中检查开发期的“不校验合法域名”选项；本轮没有自动修改这项设置。
3. 点击“同学 A”。选择已有本地旅行，上传副本，打开该协作旅行。
4. 选择邀请权限，再生成 24 小时邀请，复制口令。邀请默认只读；需要协作编辑时改为可编辑成员。
5. 点击“同学 B”切换调试账号，粘贴口令加入，编辑一项活动名称。
6. 切回“同学 A”，点击刷新，即可看到 B 的修改。
7. 可用“同学 C”验证未受邀无权访问，以及只读邀请不能编辑。创建者可以修改已加入成员的权限。

调试账号用于开发者工具本机验证，不代表真实微信账号。此次 HTTP 验证在独立后台数据库留下一个杭州测试旅行；没有读取/上传开发者工具中用户的真实数据。

## 真正的微信账号

微信登录代码已接入 WxJava，但仍需要你在后台机器配置自己的 WECHAT_APP_ID 与 WECHAT_APP_SECRET；不要将 AppSecret 发到聊天或填入小程序代码。默认启动模式关闭调试账号。

两台手机无法通过电脑的 127.0.0.1 访问服务。双人真机联调需要共同访问的 HTTPS 后台地址、微信请求合法域名配置和实际登录凭证；当前没有购买云服务或部署公网。分享邀请不会自动授予权限，接收者需要连接同一个后台、登录并点击加入。

## 当前可用范围

- 上传单次旅行副本，包含活动、账单、AA 成员分摊结算、清单与日记文本，图片文件不上传。
- owner/editor/viewer 三角色、成员权限管理、邀请过期/撤销与重复加入处理。
- 后台活动名称编辑、手动刷新同步；旧版本保存失败会明确提示刷新。
- 打开“日程与 AA 账本”可编辑活动、成员与普通/AA 消费，确认及撤销结算；后台按整数分计算余额。

本地与后台是两个独立副本；本地后来记账不会自动同步。创建上传带幂等标识，同一页面原内容重复点击不会新建多份；关闭页面再重新上传可产生另一份副本。撤销邀请不会踢出已经加入的人，可将该成员改为只读。邀请持有人会获得对应旅行完整副本的读取权，包括日记文本和账单。

数据库写入使用事务和版本条件更新。当前快照模型通过专用 actions 接口修改账单/活动，尚未细拆数据库表，未添加生产限流及完整审计、删除账号/离开旅行、定时同步或远程数据导出。
