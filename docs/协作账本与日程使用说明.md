# 协作日程与 AA 账本

## 入口与使用

我的 → 协作旅行 → 打开已上传/已加入的旅行 → 日程与 AA 账本。

- 日程：按日期添加活动，编辑名称、时间、备注，上移/下移排序，或删除。删除最后一个活动保留当天日期。排序不自动调整时间，请自行核对时间安排。
- AA 成员：添加称呼、改名、删除未被账单或结算引用的成员。AA 成员是记账身份，与登录账号和协作权限独立。
- 账单：选择普通消费或 AA 平摊，填写金额、说明、分类和日期；AA 消费还需选付款人与参与成员。可编辑原账单或删除，不能通过编辑直接转换 AA 类型。
- 结算：核对建议并真实转账后，点击“已线下支付”。结算不增加总支出；撤销只改变记账标记，不退回真实转账。
- 同行人：打开相同协作旅行，点击刷新查看新账单、余额和活动。自己从编辑页返回旅行页时会刷新当前副本。

金额由后台按整数分平摊，余数按 AA 成员添加顺序分配。例如 0.01 元两人平摊为 0.01/0.00 元。成员改名不改变历史账单关联。编辑、删除消费会重算预算及分摊，已经记录的实际转账仍保留，可能产生反向结算建议。

## 冲突及重复提交

每次写入携带版本和操作标识，后台事务锁住旅行后检查版本。多人修改旧版本时返回冲突；页面刷新后台数据并保留表单，核对后再次点击保存，不会自动覆盖他人修改。

网络结果不明确时，同一页面、同一内容重试保留原操作标识和原版本，后台已经成功执行的操作不会重复新增账单或结算。若关闭页面再重新输入，会生成新操作标识，因此网络异常后应先刷新核对是否已有该条记录。不要将“重试幂等”理解为无限期自动识别内容重复。

只读成员只能查看，后台也拒绝所有写操作；未加入的用户不能访问私密旅行。成员删除存在历史引用时会明确拒绝，避免破坏分摊。结算请求只接受当前后台建议的确切金额，不能绕过页面随意确认金额。
