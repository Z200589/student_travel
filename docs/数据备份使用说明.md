# 数据备份与恢复

入口：我的 → 备份与恢复。

1. 点击“生成当前数据备份”，检查旅行、账单、日记数量。
2. 点击“分享备份文件”，自行选择保存到自己的微信会话；或复制完整文本，保存在电脑文本文件中。生成本身不等于已保存到外部。
3. 需要恢复时，将备份文件中的完整 JSON 文本粘贴到页面，点击“检查备份内容”，检查数量，再点击恢复并确认。

备份包含 trips、expenses、itinerary、places、packing、food、diaries 原始集合，保留 AA 成员、按分记录的分摊、结算和活动。图片只保留记录中的路径，不打包图片本身，换设备后原图片路径可能不可用。昵称、主题、登录信息及其他设置不包含在内。备份包含个人旅行、日记及同行人消费信息，分享对象由用户手动选择。

恢复仅支持七个业务集合均为空的环境，遇到已有记录或损坏集合会拒绝写入。不要为试验恢复而删除唯一一份真实数据。备份版本不符、格式异常、重复 ID、AA 分摊或结算异常会拒绝。最多接受 50 万字符；大于此限制不会生成截断备份。

写入失败会尝试恢复此前空集合或移除新写入键；如果回滚也失败，会明确提示保留备份、暂停记账。当前 wx 本地多键存储不是数据库事务，恢复途中强制关闭或设备断电仍可能产生部分写入。后续可增加持久化恢复日志。正常同步失败回滚已有测试，但不承诺断电原子性。

验收：1449 原断言及 60 回归测试通过（本次新增 5 项）；28 WXML、28 WXSS 编译通过。测试覆盖完整 AA/日记往返、已有数据拒绝、部分失败回滚、坏备份拒绝及本地读取失败。微信文件分享兼容性与实际手机恢复仍待验收；API 不可用时提示使用复制文本。

下一步优先：成员名称及账单编辑；随后接入微信登录与多人同步后台。当前备份不提供多人实时协作。
