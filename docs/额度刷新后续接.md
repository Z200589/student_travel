## 4. 已完成的协作后台及页面

Spring Boot 3.5.16 + H2 文件库，WxJava MiniApp 4.8.0。服务及数据库在 backend 内，target/data/密钥文件已忽略。

后台：
- 微信 code2Session 代码已接入；密钥从 WECHAT_APP_ID、WECHAT_APP_SECRET 环境变量读取，不放前端，不要求用户把 Secret 发到聊天。
- 随机会话令牌、哈希存储、7 天过期、退出登录。
- owner/editor/viewer 三角色；后台逐次校验；未加入用户读旅行返回 404，只读不能写。
- 24 小时随机邀请令牌哈希、过期、撤销、重复加入；撤销不会移除已加入者，重复加入不会提升旧角色。
- 创建提交幂等；旅行版本检查；多人冲突返回 409。
- 旅行为 H2 CLOB JSON 快照，尚未规范化为独立活动/账单表。
- `POST /api/trips/{id}/actions`：事务锁住旅行、检查角色/版本，operations 表保存 trip/user/op 唯一标识和请求哈希。成功重放不重复记账。
- actions：add/update/deleteExpense；add/rename/removeMember；settle/undoSettlement；add/update/delete/moveActivity。
- AA 分摊由后台整数分计算，结算只接受当前建议确切金额。有历史付款/分摊/结算引用的成员不能删除。
- GET 旅行附带 Ledger 计算的总支出、共享消费、成员余额、建议及结算。普通账单不进入 AA 分摊，结算不增加支出。
- 旧 PUT 全快照禁止更改 expenses、aaMembers、aaSettlements，以免绕过专用操作校验。

客户端入口：我的→协作旅行→打开旅行→日程与 AA 账本。
- 配置后台、微信登录、本机调试三账号、上传单次旅行副本、邀请口令/分享、加入、角色管理。
- 手机表单：普通/AA消费增删改，AA成员增删改名、结算/撤销，活动名称/时间/备注增删和日内排序。
- 409 自动刷新后台数据，保留草稿，用户核对后再次保存。未知网络结果相同内容重试沿用原操作标识和原版本。
- 付款人及活动日期按稳定 ID 选择，刷新/排序后不会按旧数组位置误写。
- 自己返回协作主页面时刷新；其他同行人手动刷新，没有轮询/实时推送。
- 本地旅行和协作副本仍独立，没有自动合并或写回本机。只上传所选旅行相关记录；日记图片二进制不上传。
- AA 记账成员与协作登录账号相互独立，不要自动把三调试账号当成三个 AA 成员。
- 页面关闭后重新提交同内容会产生新操作标识，因此网络异常后先刷新核对是否已经有该账单。
